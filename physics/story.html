PART 00

题目原文

THE PROBLEM
精密条纹相机通过将时域信号转换成空间信息，实现超短激光脉冲持续时间的测量。待测激光脉冲的持续时间为 Δt，经狭缝和聚焦透镜入射至真空条纹管的光电阴极中心。光电效应产生与激光脉冲持续时间相同的电子脉冲。电子脉冲先后经加速和偏转打到荧光屏上。
阳极与光电阴极间加速电压 U₁、距离 d₁；偏转极板间距和长度分别为 d₂、L₂，其左端与阳极距离 L₁，右端与荧光屏距离 L₃。电子初速度忽略，不打到极板上；电子质量 m、电荷量 e；不计重力、相对论效应及电子间相互作用。以荧光屏中心 O 为原点、竖直方向为 y 轴。（h = 6.63×10⁻³⁴ J·s，c = 3×10⁸ m/s）
(1) 多碱、Au、CsI 三种光阴极材料逸出功约为 1.1 eV、4.5 eV、6.2 eV。要使波长 200~900 nm 的激光都能打出光电子，定量分析应选哪种材料？
(2) 偏转电压 U 为常数时，求电子打在荧光屏上的位置。
(3) 真实情况下 U = U₀ + kt（U₀、k > 0），零时刻与激光脉冲刚入射光电阴极的时刻相同。
① 求最后进入偏转极板间的电子离开极板时 y 方向速度；
② 若 L₂ ≪ L₃，求电子脉冲在屏上的空间宽度 Δy 与 Δt 的关系。

PART 03

第 (1) 问 · 光阴极材料的选择

PHOTOELECTRIC THRESHOLD

爱因斯坦光电方程：hν = W₀ + Ek——光子先"支付"逸出功 W₀，余额才是电子动能。支付不起，电子一个都不出来。波长越长，光子越"穷"，所以最难的是 λ = 900 nm 那端。

光电小实验 // LIVE —— 选材料、调波长、发射一个光子试试：

激光波长λ900 nm
光阴极
（多碱）
当前光子能量 E = 1.38 eV，逸出功 W₀ = 1.1 eV
定量计算 900 nm 光子能量
E = hc/λ = (6.63×10-34 × 3×108) / (900×10-9) = 2.21×10-19 J ≈ 1.38 eV
门槛比较（小实验里已经亲手验证）
多碱 1.1 < 1.38 ✔ ｜ Au 4.5 ✘（只能响应 λ ≤ 276 nm）｜ CsI 6.2 ✘（只能响应 λ ≤ 200 nm）
ANSWER · (1)
选用 多碱 光阴极
W₀ = 1.1 eV < 1.38 eV = E(900 nm)，唯一满足全波段响应
PART 04

第 (2) 问 · 恒定电压下的落点

STATIC DEFLECTION

回到实验台模式 A：拖动 U，光点上下移动。把这个现象拆成三段，就是标准答案。

加速区 —— 动能定理
电场力做功全部转为动能，初速为零：
eU₁ = ½mv₀²　⇒　v₀ = √(2eU₁/m)
偏转区 —— 水平匀速 + 竖直匀加速（类平抛）
场强 E = U/d₂，加速度 a = eU/(md₂)，穿越时间 t = L₂/v₀：
y₁ = ½at² = U L₂² / (4d₂U₁)　；　vy = at = eU L₂ / (md₂v₀)
漂移区 L₃ —— 不受力，沿出射角直线飞屏
y₂ = vy · (L₃/v₀) = U L₂L₃ / (2d₂U₁)
合成 y = y₁ + y₂，提取公因子
ANSWER · (2)
y = U L₂(L₂ + 2L₃) / (4d₂U₁)
不含 L₁、d₁ —— 水平匀速段的距离不改变竖直偏转量，这是命题埋的干扰项
PART 05

第 (3) 问 · 线性扫描：时间→空间

TIME-TO-SPACE MAPPING

实验台模式 B 看到的现象：U 随时间爬升，同一脉冲里先出发的电子偏得少、后出发的偏得多，屏上拉出一道条纹，且 Δt 加倍 ⇒ 条纹宽度加倍。推导就是给这个现象一个公式。

路上时间 —— 阴极到偏转板
加速段平均速度 v₀/2（耗时 2d₁/v₀）＋ L₁ 段匀速（耗时 L₁/v₀）：
T₀ = (2d₁ + L₁)/v₀
τ 时刻逸出的电子，何时进板？遇到什么电压？
t进 = τ + T₀　⇒　U = U₀ + k(τ + T₀)

① 最后进入极板的电子（τ = Δt），离开极板时的 vy —— 代入第 (2) 问偏转公式：

ANSWER · (3) ①
vy = eL₂[U₀ + k(Δt + (2d₁+L₁)/v₀)] / (md₂v₀)
其中 v₀ = √(2eU₁/m) —— 板内穿越时间极短，穿越期间 U 视为不变

② L₂ ≪ L₃ 时，Δy 与 Δt 的关系 —— 板内偏移忽略，落点 ≈ vy × (L₃/v₀)：

y(τ) ≈ eL₂L₃[U₀ + kτ + kT₀] / (md₂v₀²)τ = 0 与 τ = Δt 相减，常数项 U₀、kT₀ 全部抵消
ANSWER · (3) ② · 全题核心
Δy = (kL₂L₃)/(2d₂U₁) · Δt
Δy 与 Δt 严格成正比 —— 正是你在模式 B 里亲手拉出来的那条直线关系

THE CHAIN
