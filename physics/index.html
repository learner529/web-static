先看懂这台机器激光脉冲 → 电子脉冲 → 偏转扫描 → 荧光屏条纹

电子在加速区获得速度 v₀ → 偏转区内抛物线偏转 → 出射后直线飞向荧光屏

🎯 题目在考什么

激光脉冲持续 Δt，光电效应产生同样时长的电子脉冲。如果偏转电压随时间线性增长，那么先出发的电子偏得少、后出发的电子偏得多——时间差 Δt 就被"翻译"成了屏上的空间宽度 Δy。这就是条纹相机测超短脉冲的核心思想。

1

选哪种光电阴极材料？多碱 1.1 eV · Au 4.5 eV · CsI 6.2 eV，要求 200~900 nm 全波段都能打出电子

💡 突破口：光电效应能否发生，只看单个光子能量 hν 是否 ≥ 逸出功 W₀。波长越长、能量越低——所以只要让最长的 900 nm也能打出电子，整个波段就都没问题。
算最弱光子（λ = 900 nm）的能量：
E = hc/λ = (6.63×10-34 × 3×108) / (900×10-9)
E = 2.21×10-19 J，换算成电子伏特：
E = 2.21×10-19 ÷ 1.6×10-19 ≈ 1.38 eV
逐个对比：W₀ ≤ 1.38 eV 才合格

2

U 为常数：电子打在荧光屏上的位置经典三段式：加速 → 偏转 → 匀速漂移

💡 建模：电子全程分三段。① 加速区获得水平速度 v₀；② 偏转区内水平匀速、竖直匀加速（类平抛）；③ 出偏转区后不受力，斜向匀速直线打到屏上。
加速区（U₁）：动能定理 eU₁ = ½mv₀²
v₀ = √( 2eU₁ / m )
偏转区（U，板长 L₂、间距 d₂）：场强 E = U/d₂，加速度 a = eU/(md₂)，穿越时间 t = L₂/v₀
区内偏移 y₁ = ½at² = U L₂² / (4d₂U₁)
出射竖直速度 vy = at = eUL₂ / (md₂v₀)
漂移区（L₃，不受力）：飞屏时间 t′ = L₃/v₀
y₂ = vy·t′ = U L₂L₃ / (2d₂U₁)
求和：y = y₁ + y₂，提取公因式化简
第 (2) 问答案
y = U L₂(L₂ + 2L₃) / (4d₂U₁) 注意：L₁、d₁ 不出现——水平方向的匀速段不影响竖直偏转量
区间水平方向竖直方向轨迹形状
加速区匀加速 0→v₀不动直线
偏转区匀速 v₀匀加速 a抛物线
漂移区匀速 v₀匀速 vy直线
3

U = U₀ + kt：时间如何变成空间条纹相机的灵魂——线性扫描电压

⏱️ 关键时间线：电子什么时候进入偏转板？

t = 0 激光开始入射。设某电子在 τ 时刻（0 ≤ τ ≤ Δt）从阴极逸出，它到达偏转板要花固定时间：

T₀ = 2d₁/v₀ + L₁/v₀ 加速段（平均速度 v₀/2，耗时 2d₁/v₀）＋ 漂移段 L₁（匀速 v₀）

所以它进入偏转板的时刻为 t = τ + T₀，此刻电压 U = U₀ + k(τ + T₀)。越晚逸出的电子，遇到的偏转电压越大，偏得越狠。

① 最后进入偏转板的电子，离开时的 y 方向速度

"最后进入" ⇒ 在 τ = Δt 时刻才逸出，进入偏转板时刻 t = Δt + T₀
此时电压 U′ = U₀ + k(Δt + T₀)
套用第 (2) 问的 vy = eU′L₂/(md₂v₀)（板内穿越时间极短，电压近似不变）
① 答案
vy = eL₂[ U₀ + k(Δt + 2d₁/v₀ + L₁/v₀) ] / (md₂v₀)，其中 v₀ = √(2eU₁/m)

② 荧光屏上的条纹宽度 Δy 与 Δt 的关系

💡 L₂ ≪ L₃ 的妙用：板内那点抛物线位移可以忽略，屏上位置 ≈ vy × 漂移时间（L₃/v₀）——屏上位置只由"出射角"决定。
τ 时刻逸出的电子落点：y(τ) ≈ vy·(L₃/v₀) = eL₂L₃[U₀ + kτ + kT₀] / (md₂v₀²)
脉冲最前端（τ = 0）落在 y前，最后端（τ = Δt）落在 y后
相减：Δy = y后 − y前，常数项 U₀、kT₀ 全部抵消，再用 mv₀² = 2eU₁ 化简
② 答案 · 核心公式
Δy = kL₂L₃ / (2d₂U₁) · Δt Δy 与 Δt 成正比——量出条纹宽度，反推脉冲时长，测量完毕 ✔
同一脉冲里"先到"和"后到"的电子，被线性增长的电压分开，落在屏上不同高度
结

一图总结全题逻辑链

光电效应（第1问）：只比单个光子能量 hc/λ 与逸出功 W₀，盯最长的 λ = 900 nm → 选多碱
恒定偏转（第2问）：加速（动能定理）→ 类平抛（分解运动）→ 斜向匀速，三段拼接得 y
线性扫描（第3问）：给每个电子贴上"出发时刻 τ"的标签 → 电压不同 → 偏角不同 → Δy ∝ Δt
